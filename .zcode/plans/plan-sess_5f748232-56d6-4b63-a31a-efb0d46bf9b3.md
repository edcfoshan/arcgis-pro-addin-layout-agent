按 Pro 实机规格修复四项「设计器所见 ≠ Pro 所得」：

## 1. 下拉框在 Pro 里灰色、点不开 → 种示例选项、可下拉
- `tools/placeholder-addin/PlaceholderControls.cs`：`PlaceholderComboBox` 构造函数里种 3 个演示选项（`Add(new ComboBoxItem("选项 1"))` …），空下拉是 Pro 灰条点不开的直接原因
- 两个 DAML 生成器（designer-app/src/core/arcgisProValidation.ts:574、ribbon-designer/shared/arcgisProValidation.ts:575）：`isEditable="false" isReadOnly="true"` → `isReadOnly="false"`（仍不可编辑文字，但可点开下拉）
- 重编占位 DLL：`powershell -File tools/placeholder-addin/build-placeholder.ps1`（产物自动拷到 designer-app/src-tauri/resources/placeholder/，随安装包分发）

## 2. Pro 输入框内容=名字 → 清空内容、标题作水印
- 两个生成器的 editBox 行：`sizeString="${editHint||caption}"` → `sizeString=""`，保留 `editHint=标题` 作灰色水印——框内为空等输入，与真实插件行为一致

## 3. 小尺寸控件按 Pro 实机形态显示文字（大/中/小均以实机渲染为准）
- `getFootprint`：button/tool/menu/splitButton/checkBox 的 small 从 1×1 → 2×1（comboBox/editBox 本就 2×1）
- `flowItemWidth`：文字按钮公式从 middle 扩展到 small（button/tool/splitButton/menu）；checkBox 增加按文字估宽（max(2, round((20+文字宽)/32))）
- `ControlMock` 按 Pro 实机：
  - 复选框：所有尺寸都显示 勾选框+文字
  - 菜单/分裂按钮：中、小尺寸 = 文字+箭头（Pro 实机无图标，如「另存为 ∨」「更多 ∨」）；大尺寸 = 大图标+文字+箭头
  - 按钮/工具：所有尺寸显示 图标+文字
- 具体占格属性用户选中控件后在右侧检查器改尺寸即可（已有能力，不新增）
