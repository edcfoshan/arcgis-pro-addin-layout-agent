# 使用教程：从一格 Drag 到一份 Ribbon 布局

本教程只覆盖当前 Demo 真正具备的 Ribbon 布局能力。导出包内的按钮是占位类，不会执行任何业务命令。

## 1. 新建布局

启动「极思G Ribbon 设计器」，点击新建或打开示例。功能区由页签、分组和控件组成；每个分组高度固定为三行，可横向增加列来表达可用宽度。

## 2. 添加分组

点击画布上的「新增分组」。拖动分组边缘或调整列数，观察网格如何变化。空间不足时，碰撞检测会拒绝错误放置。

## 3. 拖入控件

从底部控件库选择控件类型与尺寸。当前支持按钮、交互工具、分裂按钮、工具板、菜单、画廊、下拉框、输入框和复选框。大、中、小尺寸对应不同占格；网格中的位置就是 ArcGIS Pro 功能区中的位置。

## 4. 使用图标

可以使用内置 Tabler 图标搜索，例如输入「图层」「放大」找到图标；也可以导入自定义 PNG。导出时把 16 与 32 像素图标一并写入。

## 5. 检查与保存

使用撤销、重做、保存和最近文件入口。关闭前确认项目名称与布局快照；出问题不要覆盖原有布局，另存一个新文件更容易比较。

## 6. 导出并安装

点击「导出」生成 `.esriAddInX`。双击安装，重启 ArcGIS Pro 查看功能区。只核对布局、顺序和图标，不要点击按钮期待业务功能。

## 7. 给社区反馈

GitHub Issue 请附设计器版本、Windows 版本、ArcGIS Pro 版本、操作步骤与截图。功能建议要说明真实 Ribbon 布局场景，以及现有做法哪里不方便。
