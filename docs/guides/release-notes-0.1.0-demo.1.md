# 发布说明模板 · 0.1.0-demo.1

## 这是什么

「极思G Ribbon 设计器」Demo 社区预览版。用于试做 ArcGIS Pro Add-in 功能区布局、导出 `.esriAddinX` 并验证布局观感。

## Demo 当前能做

- 添加页签、分组和九类 Ribbon 控件。
- 按网格放置不同尺寸控件，检查碰撞。
- 选择内置图标或自定义图标。
- 撤销、重做、保存与导出。

## Demo 暂不包含

- 按钮、菜单与实际业务命令绑定。
- 插件生命周期、业务代码生成和生产交付保证。
- 未经实测的 ArcGIS Pro 版本兼容承诺。

## 安装

下载安装包，核对 SHA256，双击按当前用户安装。启动后在关于页确认版本。导出包需要 ArcGIS Pro 手动安装并重启查看。

## 已知限制

- 仅承诺发布验证过的环境。
- 布局文档格式与导出结构仍可能调整。
- 应用内更新只有在安装包和 `latest.json` 完成签名验证后才可用。

## 反馈方式

GitHub Issues 提交可复现问题；GitHub Discussions 讨论 Ribbon 设计与社区方向；QQ 群仅供一般交流。
