# 发布说明 · 0.1.0-demo.2

## 这是什么

「极思G Ribbon 设计器」Demo 社区预览版。用于试做 ArcGIS Pro Add-in 功能区布局、导出 `.esriAddInX` 并验证布局观感。

## 本版修复

- 修复「检查更新」提示 `plugin:updater|check not allowed by ACL` 的问题。
- 授予 updater 检查、下载、安装权限，并授予 process 自动重启权限。
- 优化暗色主题层级，图标在暗色界面中保持清晰可辨。
- 图标资源加载失败时，用对应控件类型的矢量图标兜底，不再显示空黑块。
- 建立能力白名单回归测试，防止更新权限被意外移除。

## Demo 当前能做

- 添加页签、分组和九类 Ribbon 控件。
- 按网格放置不同尺寸控件，检查碰撞。
- 选择内置图标或自定义图标。
- 撤销、重做、保存与导出。

## Demo 暂不包含

- 按钮、菜单与实际业务命令绑定。
- 插件生命周期、业务代码生成和生产交付保证。
- 未经实测的 ArcGIS Pro 版本兼容承诺。

## 安装

下载 `JisigG-Ribbon-Designer_0.1.0-demo.2_x64-setup.exe`，核对 SHA256，双击按当前用户安装。启动后在关于页确认版本。导出包需要 ArcGIS Pro 手动安装并重启查看。

## 已知限制

- 仅承诺发布验证过的环境。
- 布局文档格式与导出结构仍可能调整。
- 应用内更新只有在安装包和 `latest.json` 完成签名验证后才可用。
